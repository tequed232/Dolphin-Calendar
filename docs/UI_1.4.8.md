# 1.4.8 日课表与横屏界面精修

1.4.8 以已冻结的 1.4.7 为基础，调整课程展示、时间轴、日期栏和主题。本版完整本地浏览器 CI 27/27 组、378 条 PASS，正式及调试构建、原签名实际覆盖升级、原生导航与 Debug WebView 验收均已完成。线上发布状态与附件哈希按 GitHub 实际结果及交付包发布完成记录核对。1.4.7 的历史测试和包哈希保留在 [UI_1.4.7.md](UI_1.4.7.md)。

## 界面范围

- 日课表顶部显示一次实际月日，星期与当天课程数作为次级信息；学期和周次降低视觉权重，保留自定义每日文案。
- 左侧时间轴独立显示两位节次编号、开始时间和结束时间。开启或关闭“显示时间”继续使用原偏好。
- 连续课程只有一张卡片，按真实开始／结束节次跨行显示。存在重叠的课程按相交时段分列；空节和午休使用简洁的空位及休息标记，不创建课程数据。
- 课程名称、地点和教师信息在可用空间内排列；长内容允许手动滚动查看。节次和时间保留在可访问名称及原课程详情中，避免重复占用卡片空间。
- 横屏依次为独立占位的导航、竖向日期栏、课程阅读区。日期栏上下滚动，课程区继续使用原页面滚动与阅读焦点；手机竖屏保留横向日期条。
- 深色模式采用低饱和课程表面及清楚的浅色文字；浅色、跟随系统、动态色和既有缩放设置保留。平铺课表只调整视觉与编辑反馈，继续使用原拖动、节次调整和冲突确认。

详情、教材、课程编辑和主导航复用原入口。此次不改写保存、导入、解析、学期或课程状态实现，不增加数据库迁移。1.4.7 已完成的 JSON／CSV／Excel 作息配置与时间保存继续使用原实现。

| 展示文件 | 本版变化与复用关系 |
| --- | --- |
| `DayTimetable.tsx` | 新日课表展示组件；使用原课程、逐节作息、休息标记和当前时间线，课程按钮仍进入原详情 |
| `timetablePresentation.ts` / `TimetableGrid.tsx` | 将原平铺的课程分列算法提取为共享纯展示函数，日课表与平铺共用，原编辑与保存处理保留 |
| `Home.tsx` / `InfiniteDateStrip.tsx` | 日期信息层级、横屏布局与连续日期轴方向；保留 181 项窗口、所选日期协议、节假日和阅读焦点标记 |
| `app.css` / `tokens.css` / `timetable.css` / 页面与编辑样式 | 时间轴、卡片跨度、课程颜色、响应式排列与状态反馈；继续读取既有主题、动态色和缩放设置 |

已保存课表的无课日期保留真实节次轴与空位，新安装的空课表使用导入／手动添加入口。两者没有生成示例课程或空课程数据。

## 本版验收结果

验证使用隔离浏览器、独立 Android 模拟器和合成课程，不将用户原始截图或课表发布到仓库。新日课表专项覆盖实际开始／结束行、每门课程唯一卡片、三门冲突分列、空节与午休、完整时间轴、长内容滚动、横屏三列、详情教材和日期／节次／课程焦点往返。日期栏专项覆盖真实上下／左右触摸、连续窗口补充、节假日标记、缩放、旋转和减少动态效果。

旧测试迁移标题、布局选择器和真实点击位置，继续检查原日期选择、时间显示偏好、文件导入、保存／取消、冲突处理、阅读焦点、时间线、键盘避让、离线与缓存升级。当前日期标题以实际月日核对，不再依赖旧“今天”字面标题；横屏日期滚动按真实纵轴核对，手机横轴断言保留。卡片不再重复显示时间，原精确时段断言迁至可访问名称，详情内精确时段仍继续核对。

时间线的课程点击／长按测试在同一条线与课程主体的实际交点取命中位置，避免误点既有“调整”入口；没有将测试点移出时间线。长课程内容使用真实 Chromium 触摸手势，核对内部滚动、主页面及日期栏不动、未误开详情且数据不变。
