# 1.4.9 完整课表模板与 AI 导入教程

1.4.9 基于 1.4.8，完善导入引导、统一下载模板与公开教程。本版本地完整 CI、最终构建和实际覆盖升级已通过；线上 Release、Pages 与云端检查以实际发布完成记录核对。1.4.8 的历史测试和 APK 哈希保留在 [UI_1.4.8.md](UI_1.4.8.md)。

## 实际变化

- 导入页提供「CSV 完整课表模板」及「JSON 完整课表模板」。每种格式各用一份文件提供课程、全部单节作息和午休，无需分别维护课程模板与时间模板。模板中的课程、日期和作息均为合成示例，使用前替换真实资料。
- 模板覆盖单节、连堂及单双周。CSV 的作息行与课程行使用同一文件；JSON 使用 `term`、`periods`、`courses`。旧课程文件及单独时间配置仍兼容，不改变已有解析函数。
- 「向 AI 输入提示词导入课表」提供同一份转换提示词，要求先核对开学日期、总周数、逐节作息与实际周次；资料缺失或图片模糊时先询问，不能用默认日期、示例或无依据平均拆分补齐。
- 用户明确确认单节时长、课间时长及其适用规则时，可以按确认规则计算，再核对课程总时段和逐节边界。该规则不会成为应用或公开教程的学校默认值。
- 提示词弹框通过固定 HTTPS 地址打开 [图文与视频教程](https://tequed232.github.io/Dolphin-Calendar/import-guide/)，不在 URL 中附加当前课表，也不自动向 AI 上传资料。ChatGPT / DeepSeek 的对话与上传由用户在相应服务中主动操作。
- GitHub 新增 [文字与格式说明](IMPORT_GUIDE.md)。公开图文使用真实服务界面的合成演示截图，加上编号与说明文字；视频只展示 Dolphin 内提示词、粘贴 JSON、逐节预览和保存。所有公开课表、教师、教室均为虚构。

公开教程不包含学生源文件、个人会话链接或个人作息配置。页面支持深浅与系统主题、手机横竖屏和较大字体；教程媒体与应用分开发布。

模板与提示词由应用源码统一定义，Pages 下载文件在构建时生成，教程不另维护业务格式。正常应用构建只编译应用界面；教程照片、视频和公开示例仅进入 Pages 的 `import-guide/`，不进入 APK 内置 Web 资源。

课程模型、状态与持久化、课程编辑、节次调整、冲突处理、教材和背景继续使用既有实现，不增加数据库迁移或另一套导入业务。解析与预览不改原课表；点击确认后按既有规则保存，具体修改和保留项在预览中列明。

网页版、正式安装版和调试安装版仍各有独立数据。新教程不增加用户配置项，不会修改用户已保存的课表、教材或偏好。CSV 不提供学期开始日期，缺失学期配置沿用当前值，需在预览中确认；JSON 可以提供实际学期资料。
