# 前后端业务与体验审查

审查开始：2026-10-16（Asia/Singapore）。基线：GitHub `main` 的 `9280d83`，应用 1.5.1。原桌面目录是 1.4.1，本轮使用独立工作区与 `codex/business-ux-audit` 分支，不覆盖旧目录或 IDE 修改。

应用没有业务服务器。后端范围是 Android 原生桥、SharedPreferences 镜像、提醒与行程、系统日历和更新；前端范围包括 IndexedDB、课程编辑、四种导入格式、列表/平铺/搜索、插件、主题、导航与动效。

## 范围与验证

初始 1.5.1 构建、94 项纯逻辑测试、26 项工程守卫及源码准入检查通过。初始浏览器基线只执行了前段，用于发现缺陷；它不是完整验收报告。本轮修复的当前验证如下，最终完整回归结果另附于本文件末尾。

- `npm test`：96 项通过；`npm run check` 包含源码准入、变异守卫、原解析算法 SHA 检查及这 96 项业务测试。
- `check-settings-autosave.mjs`：5 组真实浏览器检查通过，包括存储延迟、中文组合输入、失败与离开、台词持久化、保存中继续编辑并立即返回。320×568 / 深色 / 135% 字号检查无横向溢出；截图为 `build/evidence/audit-school-error-dark.png`。
- `check-import-loading.mjs`：HTTP 首屏不请求导入模块；HTTP 分块与双击离线页面均实际导入 Excel、搜索并刷新保留数据。离线页面只允许原有官方更新检查请求，没有为导入新增网络请求。
- Android `assembleDebug`、`testDebugUnitTest` 和 `lintDebug` 通过；30 项 JVM 测试，lint 0 错误、34 项既有警告。
- Android 16 只读模拟器四项检查通过：APK 本地 HTTPS 按需加载和 JSON 预览、相同提醒批次保留、距离触发 678 ms 重排保留、关闭提醒撤销。原生偏好恢复后逐字比较一致；模拟器已关闭。没有操作手机或正式应用包。
- 最终首屏 JS：827.87 → 432.54 kB，减少 47.8%；gzip 277.31 → 142.17 kB，减少 48.7%。约 397.84 kB 导入代码在使用时加载。双击离线 HTML 为保持 file:// 兼容仍包含完整代码，不能声称它也获得相同首屏下载减少。
