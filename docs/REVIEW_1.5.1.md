# 1.5.1 插件与通知展示记录

基线为1.4.11提交 `c2633c605e845534046197fbf5828f4ede3933a5`。根据用户最终要求，版本为1.5.1，插件只保留设置中的管理页，不接入或替换内置课表页。

## 改动与保留范围

- 独立插件数据库、代码包校验、手动安装／更新／启停／卸载、权限确认、专属配置和样例下载。
- 工具按需在管理页运行；关闭、离开、打开详情／导入／确认或刷新后需重新主动打开。四个原入口、列表／平铺／搜索、原编辑、拖动和数据结构保持。
- SDK提供课表快照、复用原`coursesOn`、日期选择、内置详情、主题上下文、专属配置和请求原导入预览。原JSON／CSV／Excel算法、确认保存及教材保留规则未重写。
- 应用主题由用户另行选择，只覆盖声明的颜色，移除后恢复原偏好。插件HTML／JS在独立iframe运行，不能直接取得宿主DOM、IndexedDB或原生对象。
- Android改为来源与主frame校验的消息桥，单线程串行解析以维持原有sync/history顺序。不支持隔离的旧WebView继续使用内置桥但不执行插件。
- 展开行程通知仅标题课程、无地址正文、地图按钮唯一完整地址；计时／数字阶段关闭。收起短楼栋、品牌图标、“我到了”、原ID／Intent／token／过期规则保持。
- README技术栈和[API文档](PLUGINS.md)、[TypeScript接口](../web/src/plugins/api.d.ts)、[完整示例](../web/src/lib/pluginExample.ts)一起提供。
