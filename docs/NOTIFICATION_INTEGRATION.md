# 上课提醒、导航行程与系统实时更新

从 1.2.2 起，“Android 实时通知”是总开关，上课提醒、导航行程和通知栏小伙伴分别控制。行程显示期间，小伙伴自动隐藏；行程结束后按设置恢复。“模拟导航课程并检查状态”会发出约一分钟的行程卡，不打开地图，可核对当前设备是否实际提升了通知。

本地流程是“课前提醒 → 用户点击去教室 → 用户点击我到了”。课前提醒展示课程、开课时间、完整教室、已标记教材及用户台词，使用普通通知。“去教室”先回到应用，检查学校和楼栋，再让地图只搜索“学校 + 楼栋”；完整教室号仍留在应用和通知卡片中。地图成功打开后撤下该课程的提醒。只有“显示上课行程”开关开启且通知获准时，应用才发布最长 30 分钟的持续通知。行程卡的阶段与导航按钮显示“去XX栋XXX号教室”，重新打开地图时仍只搜索学校和楼栋。“我到了”通过后台广播直接撤下行程、取消超时，不拉起应用、不补发到达通知；在设置中结束行程或关闭开关则直接撤下。

Android 16 的标准实时更新请求仅用于这个由用户主动开启、可明确结束的行程。通知采用系统 `BigTextStyle`、`ongoing`、标题、短状态文本和 `android.requestPromotedOngoing`；不使用自定义视图或强制着色。从 1.2.7 起，导航实时卡不设置 `largeIcon`，去掉左侧图；ColorOS 系 Android 16 起的 `smallIcon` 直接绑定原图缩放后的本地 256×256 彩色 PNG，而不是剪影；其他系统用新版品牌的单色兼容图标，避免原生 Android 将整张彩图染成方块。使用资源型 Icon，避免 Bitmap 型 Icon 被框架在发布时缩减。系统可能对小图标染色，ColorOS 的最终颜色需实机复核。普通提醒仍可显示用户教材封面；无封面时使用新版品牌图，旧黄色书本占位图已移除。课程与教室在标题，三步状态在副标题与正文，按钮是标准通知动作。系统决定封面、正文和按钮的最终排布，所以不会与草图逐像素一致。应用检查当前通知的 `hasPromotableCharacteristics()` 和 `FLAG_PROMOTED_ONGOING`，只在系统实际设置该标记时显示“已提升”。权限、系统版本、通知渠道和设备策略都可能让它保持普通通知。[Android 官方实时更新规范](https://developer.android.google.cn/develop/ui/views/notifications/live-update?hl=zh-cn)明确排除了普通提醒与即将到来的日历事项，并禁止实时更新使用自定义 RemoteViews。

历史 1.2.0 在 realme RMX6688（Android 16）上，打开系统应用通知设置里的“流体云显示实时活动”后，持续行程通知实际获得 `PROMOTED_ONGOING`，在通知栏顶部展示封面占位图、课程/教室、`去教室 · 2/3` 与两个操作按钮；“我到了”实测撤下持续卡并显示短时 `到了 · 3/3`。这证明系统标准实时更新已被 ColorOS 提升，但**不等于已接入 OPPO 专用潘塔纳尔服务卡片**。[OPPO 流体云模板文档](https://open.oppomobile.com/documentation/page/info?id=12658)将专用卡定义为 OML 服务；[快速开始](https://open.oppomobile.com/documentation/page/info?id=12639)要求授权码、意图和服务 ID；[服务发布指南](https://open.oppomobile.com/documentation/page/info?id=12715)还要求企业开发者认证、商务定邀及评估。后续获得开通后才能另建专用服务卡片。

[小米超级岛指南](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2131)描述了 `miui.focus.param` 与场景模板；[接入流程](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2132)要求能力开通与场景审核。当前只检测相关系统能力，不发送未经确认的模板参数。

验证时分别检查：提醒的真实课程/教材/地点、点击“去教室”后原通知是否撤下、行程通知的两个按钮、应用在后台时点“我到了”是否直接撤下行程且未拉起 App、未补发到达通知；再用设置页“检查当前行程展示状态”确认系统是否实际提升。realme 实机已验证标准提升和通知栏排版；OPPO 与小米的专用服务卡片仍需各自授权后的实机联调。

## 1.4.0 本次验证

同一课程的导航重复触发不会重置计时或延长结束时间；每段行程带独立令牌，旧卡片的到达或超时回调不能撤下新行程。Android 16 的短状态内容限制为可显示的短楼栋名称，长名称使用“去上课”。

本次使用 Google Android 16 专用模拟器及独立调试包，8 项通知流程检查和 12 轮导航开始、结束、超时与小伙伴恢复检查通过，测试后恢复原调试数据。模拟器通知保持标准持续通知，未获得 `PROMOTED_ONGOING`。历史 realme 的流体云证据不代替 1.4.0 的 ColorOS 实机复核，也不作为本版本已经提升的结论。
