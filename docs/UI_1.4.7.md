# 1.4.7 日期条与上课时间布局记录

本版以 1.4.6 为基础，处理浏览器评论指出的两处布局问题：宽屏日期之间的空隙过大，以及上课时间输入把节次标签挤压遮住。月历的单一年份控件、原生导航与其他业务沿用 1.4.6；历史记录见 [UI_1.4.6.md](UI_1.4.6.md)。

## 界面变化与源码范围

宽屏日期面板的最大宽度为 **592 CSS px**。可用空间足够时，七张日卡约为 76 CSS px，卡片间距约为 6 CSS px，日期不再随整个宽窗口拉开。手机继续使用原来的四张可见日卡布局，左右拖动、日期点选及阅读焦点逻辑不变。

上课时间的节次标签预留足够列宽，保持“第 1 节”到“第 24 节”完整显示；两个原生时间输入各限制在约 110.5 CSS px 内，不再填满宽屏行。可用宽度较小时标签移到时间上方；极窄、大字体下，标签保留在左侧，开始和结束时间上下排列。布局按实际内容宽度响应，避免缩放后仍把所有字段挤到一行。

应用实现只修改 `app.css` 与 `responsive-navigation.css` 的对应样式。未修改 `ScheduleSettings.tsx`、`InfiniteDateStrip`、时间输入类型、值和事件、自动顺延、日期选择、导入解析、存储或提醒业务；数据库及课表格式不变。原交付包的 123 项哈希基线继续保留，未重新生成基线冒充源码未变。
