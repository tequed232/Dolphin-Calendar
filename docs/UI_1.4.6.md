# 1.4.6 年份控件合并与覆盖升级记录

本版以已发布的 1.4.5 为基础，修正月历展开后年份输入与年份滑动条重复展示的问题。1.4.5 的导航、横竖屏布局与业务功能继续沿用；历史改造及验证记录见 [UI_1.4.5.md](UI_1.4.5.md)。

## 界面变化

点月历的年月标题展开选择区后，只保留一套年份控件：中间数字可以直接输入，左右箭头可以切换上一年或下一年，同一区域可以左右拖动切年。数字与拖动预览使用同一状态，避免同时出现两行相同年份。月份选择、月历日期点选、左右翻月、跨年、回到今天、课程圆点和假日标记继续保留。

本次不改变课表数据格式、数据库版本、导入解析、保存队列、提醒、系统日历或更新下载实现。原交付包的 123 项 SHA-256 基线继续保留，日历组件与样式仍在已审阅的 UI 修改范围内，未列入范围的应用源码和资源继续严格校验。

## 配置与覆盖升级

发行版本为 **1.4.6 / 10406**，包名继续为 `com.dolphin.calendar`，正式构建使用原发行签名。已发布的 1.4.5 和之前的 Release 保留。覆盖升级无需卸载或清除应用数据；具体覆盖安装、数据保留及最终签名结果须以本版实际验收记录为准。

Android、网页与调试 APK 的本地数据各自独立。本版不增加配置开关、权限或服务。年份选择仍限制在 1900–9999；本轮已重新验证输入和手势的边界、取消及键盘行为，具体结果如下，不沿用 1.4.5 的记录作为本版验收。

## 测试脚本调整

1.4.5 的本地完整浏览器回归为 22/22 组；发布后的云端运行曾为 21/22 组，首页交互脚本在普通返回结束布局编辑后立即统计拖动把手，未等待 React 提交状态。该测试调整为等待编辑状态实际退出后再检查把手消失，保留普通返回、预测返回取消、退出应用消息和阅读位置的原断言，不修改应用的返回实现。

1.4.6 的验收范围包括唯一可见年份控件、直接输入、左右箭头、同区真实拖动、年份边界与取消、月份选择，以及窄屏、较大字体和横屏。工程守卫、数据测试、完整浏览器 CI、Android 构建与原生集成、覆盖升级、APK 与 Web 资源一致性及 Pages 发布路径均按当前版本重新执行，完成状态见下表。

## 验证结果（2026-10-10）

本版完整本地浏览器 CI **22/22 组通过，共 286 条 PASS**，汇总记录 `completed=true`、`success=true`。其中日历真实触摸 11 组、原日期选择 14 项、首页交互 23 项均重新通过。日历覆盖唯一年份控件、直接输入、左右箭头与拖动、输入内触摸和方向键隔离、取消、年份边界及减弱动画。数据测试 60 项、工程守卫及双向变异 24 条通过；原交付包 123 项 SHA-256 保留，其中 106 项严格一致、17 项属于明确列出的 UI 修改范围。

横屏 844×390、110% 缩放下展开年月后，“回到今天”完整显示并可直接点击；320px、110% 窄屏可滚到完整底部操作并实际回到今天。README 的本版截图来自这轮合成数据验证。

正式与调试 APK 构建成功，Android JVM 2 项单测通过，Release lint 为 **0 错误、34 警告**。包名 `com.dolphin.calendar` 与原发行证书保持一致，版本码 **10405 → 10406** 校验通过。8 个 APK 内置 Web 资源与最终 `web/dist` 逐一匹配；Pages 本地构建及项目子目录、JSON 导入与持久化、旧缓存升级、离线回退和缓存隔离检查通过。
