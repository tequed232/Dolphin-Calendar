# 课表导航与导入交互验收

在既有 React / TypeScript / Kotlin 应用内重构，复用 Schedule、AppState 保存队列、课程详情/编辑器、Parser 和导航。用户已确认：**点击查看，长按编辑**。1.4.5 一级导航取代透明 Dock：竖屏底栏、横屏/宽屏侧栏，固定为 **列表 / 平铺 / 搜索 / 设置**，不增加第二套课表状态。

| 问题 | 修改要求与当前实现 | 验收标准 |
|---|---|---|
| 同一周切日期导致课程消失 | 周课程集合只由 Schedule 和周一日期决定；固定七天，日期条周末偏好不改变网格 | 10 月 6→7及同周七日切换，课程 ID、日期及跨度一致；仅选中日期变化；另一周显示该周课程 |
| 编辑无法退出 | 明确选中课程与编辑状态；点击查看、500ms 长按或明确“调整”进入编辑 | 默认无把手、不可拖动；仅当前课程有把手；空白、另一课程、完成、弹窗、切页/模式和 Android 返回立即退出 |
| 拖动与 Resize 控件混乱 | 主体移动，顶部/底部纵向把手改变起止节次；8px 阈值；松手后走原保存队列 | 不出现左右大型把手；至少一节，1≤开始≤结束≤最大节数；冲突仍可确认/取消；取消手势不保存 |
| 导航遮挡后续节次 | 内容容器按实体导航真实高度或宽度占位；二级任务、弹层及键盘期间隐藏导航 | 14 节最后一行可完整滚到内容区内；原生 28/32px 安全区下内容可见 |
| 导入页双重导航 | 所有二级任务隐藏实体导航，顶部返回；完成弹出当前任务路由 | 从列表/平铺取消回原位置；从管理导入完成回管理，不跳回默认主页 |
| 导入步骤只有说明文字 | 五步状态组件：选择文件→识别格式→解析校验→预览变更→确认导入 | 当前步骤有强调及 `aria-current=step`；完成/未开始有独立状态；预览确认前不改数据 |
| 选格式与选文件重复 | 文件优先，通过扩展名及内容识别；失败/不符才人工确认 | JSON/CSV/XLS/XLSX 直接进入对应解析；JSON 命名为 CSV 时具体提示并允许确认为 JSON |
| JSON 配置不同步 | 统一模型校验后提交整个 Schedule；表格缺省配置沿用 | JSON 的开学日期、12 节及第一节 08:20 同时更新；CSV/XLS 提供的上/下课时间应用到内置课时，缺失配置保留；预览明确列出修改与保留 |
| 顶部控制过密 | 列表与平铺工具栏采用普通文档流，随页面正常滚动；下一行管理+周导航；展示切换由主导航提供 | 无顶部列表/平铺分段控件；更新有新版才显示，添加/导入位置稳定 |
| 图标含义不明 | 添加固定为临时课程，导入固定为课表；有名称、Tooltip及任务标题 | 辅助技术可找到“添加临时课程”“导入课表”；支持格式在选文件前可见 |
| 切换丢失位置 | 唯一 ViewFocus 记录课程/日期/节次，由两布局映射；编辑与焦点分离 | 列表周三 5–6→平铺仍舒适可见；平铺周五→列表不跳周一；退出编辑仍保留课程焦点 |
| 当前时间强制拉回 | 首次无操作时定位一次；手动滚动/选日期后尊重浏览 | 时间更新不滚动；重复点当前一级项不重置滚动/日期或编辑状态 |
| 卡片文字过碎 | 名称→地点→教师→节次；按高度隐藏低优先级信息，详情完整保留 | 单节卡片无教师/节次挤占；长名称有完整详情语义；横向浏览时时间列不被裁掉 |
| 跨节尺寸与时间不符 | 非等距行高来自课时/课间，长休息压缩展示；实际边界吸附 | 午休行高度不同；跨节卡片顶部/底部对齐节次，末尾课间留空；编辑描边不改变尺寸 |
| 设置与课表重复 | 恢复简介及课表与日常/偏好设置/应用与数据三组；管理集中学期/课程/时间；导出恢复集中数据页 | 设置的课表管理打开已有管理页，学期和时间共用同一配置，无重复表单；管理与主页复用同一个导入页面 |
| 版本号重复 | 设置“关于”只显示内容摘要，具体版本在关于页 | 设置根页没有重复 `Dolphin Calendar · 1.4.3` |
| 留白及卡片过大 | 保持圆角、现有材质和深浅主题，压缩标题、列表项与内边距 | 320px、110% 字体、横屏无页面横向溢出；按钮完整可见 |
| 重复数据源或重载 | term/periods/courses 只在 Schedule；根切换只保存显示偏好 | 切列表/平铺/搜索/设置不重新读取课表，不重发 ready/sync，不重新安排通知 |
| 旧版偏好/课表丢失 | 兼容 `viewMode`，现有 `timetableMode` 优先；数据库版本不变 | 旧 grid 偏好启动进入平铺，切列表后刷新保持；课程 ID、教材、背景及原偏好保留；空完整备份与隐藏课程可恢复 |

1.4.5 工具栏与导入验收包含：工具栏普通文档流、星期与课程不重叠、编辑说明换行真实占位、焦点连续、设置共享配置、正常文件自动预览、返回修改不重新读取、多工作表选择保留、小屏和横屏确认按钮可操作。旧 Dock 材质、滚动自动显隐的断言已迁移为真实占位断言。结果为 `build/evidence/toolbar-import-results.json`。

本轮真实文件自查包含 21 项通过：`custom-timing.json` 自定义学期及 12 节时间、`custom-timing.csv` 连堂起止边界、`custom-period-times.csv` 14 节完整时间表，以及非法时间/冲突/取消保护。它们通过实际文件选择、预览、确认和刷新，检查主页、时间设置、课程节次选项和原生同步；结果为本机 `build/evidence/file-times-results.json`。

浏览器验收含原生桥回调和 CDP 触摸事件，不能替代 Android 实机手势验证。构建、版本测试及 lint 的结果与 APK 资源比对记录见本机 `build/evidence/upgrade-verification.json`；完整支持格式和兼容边界见 [开发升级说明](DEVELOPMENT_UPGRADE.md)。

新增实际 JSON/CSV 午休时间文件验证：时间段和独立午休行被自动识别，预览后写入内置课时，原有课程编号/ID 不改变；重叠时间不提交，重新打开仍保留。午休沿用现有圆角信息样式显示。

## 列表日期稳定与课程长按

列表日期条、月历和跨周日期导航更新当天内容时保留当前列表位置，不再调用首次进入/视图切换的课程居中定位；列表禁用浏览器滚动锚定，避免有课/无课内容替换时自动拉动视口。首次进入和列表/平铺切换继续使用同一语义焦点，平铺同周选日仍仅修改高亮。

列表课程卡片、下一节课卡片和平铺课程及其子元素禁用文字选中和移动端文本菜单；列表长按不弹出文本菜单，平铺继续使用原 500ms 长按、8px 拖动阈值和上下把手。输入框和编辑表单保持正常编辑。`check-home-interaction.mjs` 新增逐帧日期位置与长按选择回归，并继续执行真实触摸 Resize / 浏览滚动及焦点切换验收。

平铺说明与完成按钮位于普通工具栏内部，列表不显示；浏览/编辑切换后网格按工具栏真实高度占位。时间格与课程采用圆角，课时和休息分开绘制，跨节卡片仍按实际课时边界计算。设置恢复简介卡片与三个分组，主页显示、课表管理复用已有页面。

周导航中间按钮：当前自然周显示“本周”，其他周显示“回到今天”，点击恢复今天且左右箭头位置固定。时间轴每节最少 84px，节次及两行时间保留完整内边距；实体导航显示选中状态，内容容器按底栏或侧栏分别预留空间。

当前时间线：外观里的唯一开关控制列表与平铺，默认开启。只标记今天（列表）/本周（平铺）的作息范围，使用同一课时和休息时间计算语义进度；两个布局按实际几何位置绘制半透明苍绿线。每30秒和前台恢复时刷新，不影响焦点、滚动、课程点击或布局编辑。11项专属验收包含真实JSON/CSV文件导入后重算、持久化、边界、午夜、缩放和原生同步不重复。
