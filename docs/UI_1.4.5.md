# 1.4.5 界面、配置与覆盖升级记录

本版以已发布的 1.4.4 为基础，按作者提供的界面截图改造导航与响应式布局。课表、导入解析、保存队列、提醒调度、系统日历和数据格式继续使用原实现。本轮修改包含界面实现，不能再描述为“所有源码原样同步”。

## 界面变化

- 竖屏使用实体底部导航，横屏或宽屏使用侧边导航；顺序为列表、平铺、搜索、设置。网页在宽度至少 768px，或横屏且宽度至少 480px 时使用侧栏。
- Android 导航由独立的原生 `LinearLayout`、`ImageView` 和 `TextView` 组成，支持触摸反馈、选中状态与辅助技术，位于 WebView 外。它采用平台原生 View，没有新增 Compose 或 Material Components 库。网页收到原生导航能力确认后才隐藏网页导航；旧宿主和网页保留网页导航。
- 内容视口按导航实际高度或宽度预留空间，课程和星期不再从透明 Dock 后面穿过。二级任务、课程详情、对话框和输入法期间隐藏导航，关闭后恢复。
- 列表与平铺顶部工具栏随内容正常滚动。平铺说明和布局完成按钮仍在工具栏内；说明换行后，网格按工具栏真实高度占位。需要课表管理或周导航时滚回顶部操作。
- 横屏释放原有 600px 窄画布限制，课表利用可用宽度；设置与搜索可利用宽屏分栏。短屏侧栏保留四个入口，课程详情内容可滚动。
- 对话框挂到页面根部，避免继承页面缩放后又在内容区放大一次；窄屏、大字体和横屏下标题、关闭及确认操作保持可用。
- 月历支持手指或鼠标左右拖动，跟手翻月并跨年；未完成拖动、垂直滚动和取消不会误选日期。点年月标题可展开年份输入、快捷年份和月份选择；展开后在独立可见的年份滑动条左右拖动切年，年份输入和上一年／下一年按钮继续可用。保留日期点选、课程圆点、假日标记和回到今天。

## 配置与旧数据

包名继续为 `com.dolphin.calendar`，版本为 1.4.5，版本码为 10405。正式构建仍要求原发行密钥；没有密钥时构建失败，不生成无法覆盖原正式版的替代签名包。覆盖安装前无需卸载或清除数据；卸载、清数据和浏览器清站点数据仍会删除本地内容。

数据库版本和课表格式不变。已有课程、教材、背景、假日缓存、学校、通知偏好、主题与缩放继续读取。旧玻璃参数保留在数据中，界面不再提供仅控制旧 Dock 的光泽、散射和扭曲选项。背景毛玻璃、深浅模式、界面缩放、安全区和性能模式仍可设置。导航布局随窗口方向及宽度自动变化，不增加必须配置的开关。

Android、调试 APK 和网页的数据各自独立。导出的课表 JSON 包含课程、学期和节次，不包含所有教材封面、背景图片及偏好。

## 源码范围与验证迁移

`scripts/check-delivery-integrity.mjs` 保留原交付包的 123 项 SHA-256，不重新计算并替换原基线。它为本轮明确审阅的 UI 路径建立清单，列出修改或删除原因；未列入清单的应用源码、图片资源、业务模型、存储、导入、提醒、日历与更新模块仍须匹配原哈希。混合界面与原生桥文件另通过差异审阅和行为回归，不能仅靠路径清单证明其业务行为。

原 Dock 专属透镜、按压放大和黏滞拖动检查已迁移为实体导航、真实占位、能力确认及无重复导航检查。业务断言仍保留，包括导入预览前不改数据、保存失败、课程冲突确认与取消、真实触摸拖动及 Resize、日期焦点、假日标记、覆盖升级和离线持久化。旧浮窗“永不改变高度”的断言改为检查工具栏真实高度与课程网格不重叠，允许说明正常换行。

`check-glass.mjs` 和 `check-master-glass.mjs` 为兼容既有 CI 名称保留入口，当前验证实体导航深浅主题、原生返回起点和旧玻璃偏好的数据兼容，不再声称执行折射验证。历史全界面液态玻璃、Dock 拖动设备脚本仅对应其旧版本，不能作为 1.4.5 验证证据。当前 Android 导航以 `check-native-navigation.mjs` 为准。
