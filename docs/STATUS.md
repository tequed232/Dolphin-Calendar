## 1.4.0 实现与目标状态（历史）

以普通用户从首次打开到日常使用的完整路径为目标，1.4.0 已完成引导、导入、主页、搜索、课程与教材编辑、设置、外观及返回交互优化。README 已整理为中文文档，包含真实架构、功能入口、JSON 示例、构建、验证与能力边界。该版本交付时仍等待 README 审阅、尚未上传 GitHub；后续 1.4.1 私有源码上传范围见上文，不创建 Release。

### 首次打开与日常操作

- 首次启动是可前后切换的三步向导：准备课表、查看与导航、提醒与外观。任意步可“先逛一逛”；最后可导入第一份课表、手动添加课程，或直接打开提醒/外观设置。引导不自动申请权限、不创建示例课表，也不改变已有课程。关于页可从第 1 步重新查看。
- 连续点按向导或保存不会重复跳转、创建课程或提交导入。首次完成状态保存失败时恢复按钮并允许重试；320×640、110% 比例、深色、安全区与减少动画均有检查，长说明只滚动中部，操作区留在对话框内。
- 空课表的主页和搜索直接提供导入及手动入口；无课日期说明实际星期、周次或学期范围，并可跳到下一次真实有课日期。主页导航目标与所选日期一致，下一节、上课中和已结束按真实节次显示。
- 搜索覆盖全课表的课程名、教师和教室，忽略首尾空格，显示匹配数；清除后保留输入焦点，无结果可恢复全部课程。主页月份选择、日期条和空状态共用应用月历。
- 导入突出 JSON 文本，文件选择为次级操作；导入预览改用应用月历，返回修改保留输入。学期、课程、教材和导入草稿离开前可继续编辑、放弃或保存；保存失败保留草稿，正在提交时阻止重复保存与关闭。
- 课程与教材错误提示贴近对应字段；取消未改动的新建不会生成空条目，删除需要确认。课程更名保留教材，处理封面时不覆盖已经编辑的书名、版次和文字，换行按真实换行保存。关闭教材弹窗不会连带关闭课程详情。
- 设置按用途分组，学期日期完整显示，全部课程默认折叠，背景、玻璃与屏幕安全区仍在外观内。保持固定 Dock、固定背景和原有手势风格，键盘只避让输入区。

### 关闭、部分、完全三档液态玻璃

- **关闭**：纯色页面与底栏，保留滑动、点按和弹性选择。
- **部分（默认）**：实时折射与放大透镜仅在 Dock；课程、设置等页面使用清楚的纯色表面。
- **完全**：Dock 保留透镜，主页卡片、搜索、设置、页头、弹窗及次要按钮采用共同的半透明、高光与适度背景模糊。文字、输入和主要操作保持可读；复杂位移仍只在底栏，页面表面不重复叠加昂贵滤镜。
- 三档是真实作用范围，保存后重开仍保留；旧版 `glass=true` 迁移到部分，`glass=false` 保持关闭，不强制开启完全模式。背景 0–30 px 毛玻璃继续独立调节。
- Dock 前景约 1.25 倍放大，与固定尺寸背景采样分开；三段拖动时圆角外像素泄漏均为 0，刻意去掉遮罩后检测到矩形漏光。点按从旧位置弹性移动，接近落点后才收起透镜；被草稿保护拦截时选中胶囊回到实际活动页。
- 浅深完全模式下已检查课程说明、日期与次要按钮的文本对比度；本轮最低测量值高于 4.5:1。自动性能模式在受控慢帧时实际降低质量，去除昂贵位移与大面积模糊；减少动画和返回期间保留可读表面。实现是 React / WebView 的 DOM、CSS 和 SVG 适配，没有直接导入原生 Compose 库。

## 导入课表与导航

在“设置 → 课表编辑 → 导入课表”粘贴 **JSON**，或用次级按钮选择 `.json` 文件。HTML、表格文本及其他文件格式在这个入口会被拒绝；需要时可复制应用内 JSON 转换提示词，先在外部转换。导入前核对开学日期与学校名称。学校名称用于将地图查询限定在当前校园；若未填写，首次导航会带到“导航与学校”补齐。

新导入会把可明确识别的 `16-203/202` 规范为 `16栋203号教室`；第二间教室的原始写法保留在课程备注。`博学楼 A203` 会显示为 `博学楼A203号教室`。`26-2...` 之类已截断的原文不会被编造成完整房间号；若楼栋号明确，地图仍可先搜索 `26栋`。应用向地图只传“学校 + 楼栋/楼名”，完整教室号保留在课程详情和通知中。实际地图定位仍取决于地图服务是否收录校园建筑。

导入缺少开学日期时，按学期名称年份暂设 9 月 1 日，必须在预览确认。单次保护值：5 MB、2,000 条课程、周次 1–999、约 20,000 次上课。失败不覆盖现有课表。已导入的旧数据不会被悄悄改写；重新导入 JSON 后采用新格式，旧课程在导航时也会临时识别明确的楼栋。

## 通知与实时更新

打开“设置 → 实时通知 → Android 实时通知”，再开启“上课提醒”，按提前量发送普通系统通知，展示课程、开课时间、教室、教材和台词。通知“去教室”按钮返回应用并打开所选地图；成功打开后撤下对应提醒。打开“显示上课行程”后，地图启动会创建最长 30 分钟的持续卡片：不显示左侧大图标，标题含课程与教室，阶段与导航按钮写明“去XX栋XXX号教室 · 2/3”和具体目的地。点“我到了”后直接撤下行程，不打开 App、不补发到达通知。关闭行程开关或在设置结束行程会直接撤下通知。

Android 16 的标准实时更新由系统控制排版，官方要求系统标准通知样式，不允许自定义 `RemoteViews`。历史 1.2.0 在 realme RMX6688（Android 16）打开“流体云显示实时活动”后，进行中的行程获得 `PROMOTED_ONGOING` 标记并位于通知栏顶部；当时的到达通知已在 1.2.7 移除，当前“我到了”只后台撤下行程。历史结果证明 **Google 标准实时更新被 ColorOS 提升**，当前品牌图与最终卡片布局仍需对应手机复核。OPPO 潘塔纳尔专用 OML 卡片是另一个接口，需要平台服务 ID、授权码与审核。普通课前提醒不申请实时提升。

“外观 → 深浅模式”保留“跟随系统 / 浅色 / 深色”三档，模式选择使用应用自己的圆角下拉菜单；跟随系统时，Android 明暗配置变化会同步 WebView 内容和状态栏颜色。1.4.0 液态玻璃使用关闭、部分和完全三档，默认部分；完全模式扩展共同玻璃材质，复杂折射仍只作用于 Dock 选中胶囊。拖动时弹簧跟手，点按时从原位置弹性滑动；自动性能模式在慢帧时降低滤镜负担。屏幕稳定 120 FPS 会受到设备、刷新率策略、温度和系统合成影响，当前没有做出持续 120 FPS 保证。

## 安装与开发

历史 1.4.0 交付目录为桌面的 `Dolphin-Calendar-1.4.0`，签名 APK、网页离线包、源码包、验证记录和 SHA-256 清单以该目录实际文件为准。正式更新使用签名正式 APK，调试包与正式版数据分离。私有 GitHub 仓库只接收源码及工程资源，历史本机交付文件不随此次上传。

历史 1.1.0 的旧调试版课程备份名为 `Dolphin-Calendar-course-backup.json`。需要迁移时可在正式版选择自己的 JSON 备份、核对开学日期与学校名称后确认；导出 JSON 仅包含课表、学期与节次，不包含教材封面、背景图片或全部设置。已截断的教室号应对照教务系统人工补齐。

项目可直接用 Android Studio 或 IntelliJ IDEA 打开。源码构建需要 Node.js 22.12+、JDK 17、Android SDK 36，依次执行 `npm ci`、`npm run build`、`npm run android`。正式签名保存在开发机私有 `.signing/` 与 `signing.local.properties`，不会进入源码包。网页包解压后可托管 `index.html`，或双击 `Dolphin-Calendar-offline.html`；后一种用法需保留同目录 `assets` 文件夹。
