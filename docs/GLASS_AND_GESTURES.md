# 液态玻璃与返回交互

1.4.0 保持 React + TypeScript 与 Kotlin WebView 共用界面。参考 [AndroidLiquidGlass 的 LiquidBottomTabs](https://github.com/Kyant0/AndroidLiquidGlass/blob/kmp/app/src/commonMain/kotlin/com/kyant/backdrop/catalog/components/LiquidBottomTabs.kt) 的分层、限幅与按压原则，以本项目 DOM/CSS/SVG 实现；没有直接链接 Compose 组件库。

## 三种范围

- **关闭**：纯色界面与底栏，保留点按、滑动与弹性选择。
- **部分**（默认）：仅底栏实时采样和透镜；课程与设置保持纯色表面。
- **完全**：底栏保留透镜，页面卡片、次要按钮、标题和弹窗采用统一半透明、高光及适度背景模糊。文字、输入与主要操作保留足够不透明度。复杂位移仅用于底栏，其他表面使用玻璃材质。

设置保存到 IndexedDB，重开仍保留。旧版玻璃布尔开关迁移为关闭或部分，升级不会强制打开完全模式。背景毛玻璃仍在“外观 → 背景”独立设置。

## 底栏分层

GlassDock 的背景采样层固定为 96×64 CSS 像素，使用半分辨率位移贴图、20 档轮廓和缓存遮罩。平移、按压与页面滚动不会每帧生成贴图。圆角遮罩在合成输出处约束折射，轮廓与采样遮罩使用相同档位，避免边缘错位和透明方形。

前景图标与文字独立放大至约 1.25 倍，不缩放背景纹理；选中胶囊不保留外部尾线或外投影。按住后指针由 nav 捕获，横向中心夹在底栏边界内。拖动采用弹簧滞后，点按从旧位置移至新位置；释放后接近落点再收起按压效果。被草稿保护拦截的切换返回实际活动标签。

关闭模式仍可滑动；减少动画设置会直接落到目标。输入法只缩小输入区，底栏按完整窗口固定，关闭键盘即可继续操作。

## 性能与可读性

自动性能模式只在交互短窗口采样帧间隔，空闲不运行常驻循环；检测慢帧时去掉昂贵位移和大面积模糊。完全模式避免内外表面重复滤镜，降级和返回手势期间使用纯色表面，减少透明度偏好同样采用可读的实色。

120 FPS 的呈现预算约为 8.33ms。浏览器 rAF、原生触摸回调和设备实际呈现帧不同，不能用模拟器检查承诺所有手机稳定 120 FPS。最终表现受设备刷新率、温度、省电策略与 WebView 影响。

## 返回与草稿

原生触发位置换算为当前页局部坐标，作为收拢中心。手势进度同步写到缓存的页面合成层，松手使用合成器执行约 210ms 的完整淡出；取消约 170ms 恢复。没有每帧整屏模糊。

关闭弹窗、Esc、返回与底栏切换先交给编辑草稿保护。保存成功再退出；验证或写入失败留在编辑页。预测返回触发确认后会恢复页面，再按确认结果继续，避免一边离开一边丢弃输入。

## 验证入口

- `node scripts/check-liquid-modes.mjs`：三种模式和旧数据迁移、真实拖动/点按、遮罩像素及变异、对比度、性能回退、窄屏深色、减少动画。
- `node scripts/check-glass.mjs`：局部背景真实折射、滚动采样与质量回退。
- `node scripts/check-visual-regressions.mjs`：圆角外像素、返回淡出和合成层清理。
- `node scripts/check-experience.mjs`：页面草稿保护、预测返回保存、统一导入月历与明确失败。
- `node scripts/check-dock-device.mjs`：指定隔离 Android 设备的实际触摸与帧间隔；指标不等于实体手机呈现帧率。

记录位于 build/evidence，发行包身份由 check-release.ps1 另行校验。
